# tdskill 情感导师 AI Skill 工具箱

## 📚 项目简介

tdskill 是一个面向情感成长场景的中文 AI Skills 工具箱。它从兔导的 **195 篇公众号推文累计45万字**中提炼出 **1144 个知识原子**，覆盖认知提升、展示面打造、搭讪、聊天、约会、关系管理和学习方法七大领域，并将其中的方法沉淀为 **8 个可直接调用的 Skills**。

你不需要先学会一套复杂的方法，也不需要知道该调用哪个工具。把当下的情感处境交给 `/tdskill`，它会根据对话上下文选择当前最适合的 Skill。

## 🧠 8 个 Skill 功能概述

| Skill | 作用 |
| --- | --- |
| `/tdskill` | 主入口路由器，根据问题自动选择合适的诊断 Skill |
| `/tds-attraction` | 认知提升诊断，找到吸引力层面的认知卡点 |
| `/tds-display` | 展示面与人设打造诊断，传递正确的信号 |
| `/tds-approach` | 搭讪诊断，自然地开始一次交流 |
| `/tds-chat` | 聊天诊断，建立真正有连接的对话 |
| `/tds-date` | 约会诊断，把约会变成有效的情感传递 |
| `/tds-relationship` | 关系管理诊断，建立可持续发展的长期关系 |
| `/tds-learn` | 学习方法诊断，把知识转化为行为改变 |

## 🚀 使用方式

### 基础用法

安装完成后，直接在 Agent 中输入：

```text
/tdskill 我最近认识了一个女生，聊了一周但感觉越来越冷，不知道哪里出了问题。
```

主入口会读取当前对话信息，自动选择合适的分析路径。

### 直接调用

已经知道需求时，可以直接调用具体 Skill：

```text
/tds-chat 她回复越来越慢，我该怎么处理？
/tds-date 第一次约会该安排什么？
/tds-display 我的展示面哪里需要调整？
```

## 🔧 安装命令

### 通过 npx 安装

```bash
npx -y skills add tdskill/tdskill -g --all
```

安装后回到 Agent，输入 `/tdskill 新手入门` 即可开始。

### Claude Code 插件市场

```bash
claude plugin marketplace add tdskill/tdskill
claude plugin install tdskill@tdskill
```
